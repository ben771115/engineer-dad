// 關於我

十多年後端，還在持續升級

從 2013 年開始寫程式，做過製造業 ERP、銀行整合、房仲和保險系統，主力是 .NET／C#、Oracle、Angular。

這幾年最大的興趣是 AI：不只用工具，也想弄懂它底層怎麼運作，所以下班後會自己動手實作。學到的東西、踩過的坑，都會整理成筆記分享出來，希望對同樣在路上的人有幫助。

工作之外，最重要的身分是爸爸。

// 我的筆記術：Notion

把學到的東西變成自己的

  • P.A.R.A. 分類：依「專案／領域／資源／封存」整理，找東西不迷路
  • 卡片筆記：一張卡片只寫一個想法，彼此連結，慢慢長出自己的知識網
  • 任務看板：分成上班、日常、學習三欄，一眼看到今天要做什麼
  • 每日一問：每天只回答一個反思問題，簡單才做得下去

工具免費版就夠用，重點是養成「學了就寫下來」的習慣。

// Side Project × AI 協作

為了理解而實作

現在很多 AI 代理已經很強，但我想知道它們怎麼運作，所以自己做一個。開發過程大量和 AI 協作：讓 AI 幫忙寫樣板、查文件、review，我負責架構和判斷。

C# · Semantic Kernel

自製 AI Agent Runtime

用 C# 從零打造的 AI 代理：事件驅動架構，整合 RAG、長期記憶、工具呼叫，以及本地模型（Ollama）與雲端模型的自動切換。

最大的收穫是學會「什麼該交給 LLM、什麼不該」，相關心得都寫在下面的文章裡。
